# Storybook Kingdom — Complete Interactive World

Open `index.html` in a modern browser. No installation is required.

## What Storybook Kingdom is
Storybook Kingdom is a large original fairy-tale world built for free exploration, role-play, stories, mysteries, quests, games, festivals, castle-town life, and quiet no-pressure visits. It is inspired by classic fairy-tale atmosphere while using original characters, places, and story material.

## Core experiences
- Free Explore across castle, village, market, forest, gardens, harbor, abbey, bakery, festival grounds, underways, villages, and neighboring realms
- Role-play character creator with persistent character details
- Branching original fairy tales and long-form story arcs
- Mysteries, clue boards, deductions, and replayable case files
- Quests, choice-remembering quests, and multi-part living storylines
- Festival games, riddles, memory games, fortune prompts, tournaments, masquerades, weddings, and holidays
- Just Visit / Cozy mode with no goals, scores, or required progress
- Royal Court petitions and palace life

## Living-world systems
- Recurring royals, villagers, merchants, servants, scholars, guards, performers, and travelers
- Friendships, companions, courtship-style story bonds, letters, rumors, and reputation
- Kingdom coins, shops, inventory, wardrobe, titles, keepsakes, furnishings, and property
- Homes, household routines, meals, feasts, royal kitchens, and ordinary daily life
- Carriages, boats, walking, horses, stables, favorite mount, villages, and realm passport
- Jobs, trades, castle shifts, Royal Academy lessons, theatre, music, singing, and performances
- Seasons, weather, fictional calendar, time-of-day atmosphere, seasonal arcs, and random daily events
- Storybook library and collectible kingdom lore
- Flexible life paths: royal, noble, merchant, artisan, castle servant, farm/orchard, traveler, or village resident
- Seven-chapter `From Cottage to Court` rags-to-royalty-style saga with remembered choices
- Original fairy-tale premise generator

## Navigation & comfort
- 53 connected website sections
- Kingdom Life search and category filters
- Continue Last Visit button
- Surprise Me button
- Responsive desktop/mobile design
- Reduced-motion support when enabled in the browser/operating system
- Gentle synthesized ambience toggle

## Saving & backups
Progress is stored in browser `localStorage`. The Save & Restore Center can export a JSON backup, import a previous backup, or deliberately reset Storybook Kingdom.

## Files
- `index.html` — all page structure
- `styles.css` — visual design and responsive styling
- `script.js` — interactive systems and saved progress
- `README.md` — this guide

## Hosting
Keep all four files together at the project root. This project can be hosted as a static site on services such as GitHub Pages or Render Static Sites.

## Final Release — October 2026

Storybook Kingdom has completed its base-game build. The final release includes:
- movement-based keyboard and mobile controls
- 72 connected explorable locations
- distinct interiors and environmental themes
- quests, route guidance, collectibles, achievements and save state
- relationship memory and NPC routines
- day/night and dynamic weather
- location mini-games, kingdom coins and shops
- equipable traveler cosmetics
- decorateable homes and home-base travel
- cinematic doorway transitions
- optional generated sound effects and ambience
- responsive mobile/desktop UI and reduced-motion support

Future changes should be treated as expansions or content packs rather than required base-game systems.
